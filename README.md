# Conkrner
A conky config to section off the rightmost 1/5th of a 2440x1440 secondary monitor for wayland, allowing windows to only use the right 4/5ths.
Requires waybar, files affected respectively sit as follows on my device:
`~/.config/
    waybar-strut/
        style.css
        config.jsonc
    conky/
        conky.conf
        conky-launch.sh`
